# insta-auto-post

Instagram @manabirador に、毎日21時(日本時間)に1本ずつ自動で投稿する仕組み。

- `specs/日付.json` … 1本分の原稿(7枚の文とキャプション)
- `make_carousel.py` … 原稿から画像を作り、検査に合格したものだけ `queue/日付/` に置く
- `post.py` + `.github/workflows/post.yml` … 毎日、`queue/` の一番古い1本を投稿し `posted/` へ移す
- `reel.py` + `.github/workflows/reel.yml` … 毎朝7時、前の晩に投稿した7枚を約15秒の縦長リール(無音)にして投稿する。記録は `posted/reels.jsonl`
- 昼12時の枠(2026-11-12追加、フォロワー1,000人の施策)… `queue/` の一番先の日付をリール専用で出し、`posted/日付-reel` へ移す（カルーセルには回さない）。明日以降の在庫が4本未満の日は出さない。1日2本を続けるには、週1の補充を7本→14本にする
- キャプションにタグがなければ、検索用のタグを末尾に自動で足す(`post.py` の TAGS)
- 止めたいとき … リポジトリ直下に `PAUSE` という名前のファイルを置く。1本だけやめるなら `queue/` のその日付フォルダを消す
- `private/` … 個人名の検査リスト。公開しない(.gitignore)

必要なSecrets: `IG_TOKEN`(Metaのシステムユーザートークン。期限なし)

## 原稿を選ぶときのルール（2026-11-11 追加・PDCA台帳より）
- テーマは保護者向けの3本柱にそろえる：①計算ミス ②声かけ ③家庭学習のやり方。算数の解き方そのものの話は週1本まで。
- 7本のうち2本は海外在住・帰国生の家庭向けにする（例：帰国生入試の算数の特徴、海外で日本の算数を続けるコツ、現地校と日本の算数のちがい、一時帰国中の学習）。1枚目の小見出しに「海外在住のご家庭へ」などと入れる。講師はenaシンガポール校で最上位クラスを担当した経験がある（「元ena校長」とは書かない）。
- 1枚目は親の悩みを問いかけの形で出す（例「計算ミス、見直しで減りますか？」）。文字は中央寄せで、四辺に余白をとる（一覧やリールで端が切れないように）。
- キャプション1行目に検索語（中学受験・算数・計算ミス など）を文章で入れる。タグは post.py が自動で足す。
- 詳しい方針と数字は Notion「Instagram PDCA台帳（@manabirador・正本）」。
